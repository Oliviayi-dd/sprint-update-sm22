Enablement Chain

PI3 delivery compounds through platform dependencies: OFM performance enables V1 activation, OFM V2 expands automation, and Certificate Manager unlocks independent VIC fulfilment.

  • OFM Automation V1 is deployed but depends on OFM performance improvement before activation.
  • OFM Automation V2 enables OFT to use the SKILL for remaining certificate automation.
  • Certificate Manager and OFM automation together enable the New VIC Certificate Flow.
  • KYC/KYB roadmap includes ASIC caching; Property roadmap includes bank migration for CBA and Westpac, and NSW property flow.
